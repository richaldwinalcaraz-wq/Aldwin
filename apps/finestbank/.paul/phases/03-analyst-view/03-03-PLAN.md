    Append a new endpoint to the existing analyst router in `backend/app/api/analyst.py`.

    Endpoint: `GET /portfolio`
    - Dependencies: `require_role(Role.ANALYST, Role.CFO)`, `get_scoped_db`
    - No `get_current_user` — RLS handles scoping (same pattern as /transactions)

    **Holdings query** — all holdings ordered by market_value descending:
    ```python
    rows_result = await db.execute(
        select(PortfolioHolding).order_by(PortfolioHolding.market_value.desc())
    )
    holdings = rows_result.scalars().all()
    ```

    **Allocation query** — GROUP BY asset_type, SUM(market_value):
    ```python
    alloc_result = await db.execute(
        select(
            PortfolioHolding.asset_type,
            func.sum(PortfolioHolding.market_value).label("mv"),
        ).group_by(PortfolioHolding.asset_type).order_by(func.sum(PortfolioHolding.market_value).desc())
    )
    alloc_rows = alloc_result.all()
    total_mv = sum(float(r.mv) for r in alloc_rows) or 0.0
    ```

    **Return shape:**
    ```python
    {
        "holdings": [
            {
                "id": str(h.id),
                "asset_name": h.asset_name,
                "asset_type": h.asset_type,
                "ticker": h.ticker,
                "quantity": float(h.quantity),
                "unit_cost": float(h.unit_cost),
                "current_price": float(h.current_price),
                "market_value": float(h.market_value),
                "unrealized_pnl": float(h.unrealized_pnl),
                "weight_pct": float(h.weight_pct),
            }
            for h in holdings
        ],
        "allocation": [
            {
                "asset_type": r.asset_type,
                "market_value": float(r.mv),
                "pct": round(float(r.mv) / total_mv * 100, 1) if total_mv else 0.0,
            }
            for r in alloc_rows
        ],
        "total_market_value": total_mv,
    }
    ```

    No new imports needed — `func`, `select`, `PortfolioHolding`, `AsyncSession`, `Depends`,
    `require_role`, `Role`, `get_scoped_db` are all already imported.

    Avoid: Adding `get_current_user` — not needed (RLS handles scoping).
    Avoid: Computing pct client-side — do it in the endpoint for clean separation.
    Avoid: Returning full ORM objects — serialize to dict explicitly.

    **Part A — Create `frontend/src/components/portfolio-donut.tsx`:**

    Client component following the same pattern as `revenue-chart.tsx`.

    ```tsx
    "use client"

    import { PieChart, Pie, Cell, Tooltip, ResponsiveContainer } from "recharts"

    interface AllocationSlice {
      asset_type: string
      market_value: number
      pct: number
    }

    const COLORS = ["#3B82F6", "#10B981", "#F59E0B", "#8B5CF6", "#EF4444", "#06B6D4", "#F97316"]

    function formatCompact(v: number): string {
      if (v >= 1_000_000_000) return `$${(v / 1_000_000_000).toFixed(1)}B`
      if (v >= 1_000_000) return `$${(v / 1_000_000).toFixed(1)}M`
      if (v >= 1_000) return `$${(v / 1_000).toFixed(1)}K`
      return `$${Math.round(v)}`
    }
    ```

    - Accept prop: `data: AllocationSlice[]`
    - If `data.length === 0`, render centered empty state: `<div className="flex h-[260px] items-center justify-center text-sm text-slate-500">No portfolio data</div>`
    - Render:
      ```tsx
      <ResponsiveContainer width="100%" height={260}>
        <PieChart>
          <Pie
            data={data}
            dataKey="market_value"
            nameKey="asset_type"
            cx="50%"
            cy="50%"
            innerRadius={70}
            outerRadius={110}
            paddingAngle={2}
          >
            {data.map((_, i) => (
              <Cell key={i} fill={COLORS[i % COLORS.length]} />
            ))}
          </Pie>
          <Tooltip
            formatter={(value: number, name: string) => [formatCompact(value), name]}
            contentStyle={{
              backgroundColor: "#0f1629",
              border: "1px solid #243055",
              borderRadius: "6px",
              color: "#F1F5F9",
              fontSize: 12,
            }}
            labelStyle={{ color: "#94A3B8" }}
          />
        </PieChart>
      </ResponsiveContainer>
      ```

    - Below the chart, render a compact legend row:
      ```tsx
      <div className="flex flex-wrap justify-center gap-3 mt-2">
        {data.map((d, i) => (
          <div key={d.asset_type} className="flex items-center gap-1.5 text-xs text-slate-400">
            <span className="inline-block h-2 w-2 rounded-full" style={{ backgroundColor: COLORS[i % COLORS.length] }} />
            {d.asset_type} ({d.pct}%)
          </div>
        ))}
      </div>
      ```
