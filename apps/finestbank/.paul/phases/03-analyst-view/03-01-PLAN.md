  <name>Task 1: Create analyst summary API endpoint</name>
  <files>backend/app/api/analyst.py, backend/app/main.py</files>
  <action>
    Create `backend/app/api/analyst.py`:

    Imports needed: uuid, datetime, timedelta, timezone, func, select, FastAPI APIRouter,
    Depends, HTTPException, AsyncSession, get_current_user, get_scoped_db,
    require_role, Role, and all 4 RLS-scoped models (Transaction, PortfolioHolding, Loan)
    plus Division model from app.db.models.

    Router: `router = APIRouter(prefix="/analyst", tags=["analyst"])`

    Endpoint: `GET /summary`
    - Dependencies: `_ = Depends(require_role(Role.ANALYST, Role.CFO))`,
      `current_user = Depends(get_current_user)`,
      `db: AsyncSession = Depends(get_scoped_db)`
    - Get divisions list from current_user["divisions"] — if empty, raise HTTP 400
      "No division assigned to this account"
    - Take first division UUID: `division_id = uuid.UUID(str(divisions[0]))`
    - Query Division table (no RLS): `select(Division).where(Division.id == division_id)`
      If not found, raise HTTP 404 "Division not found"
    - Transaction stats (last 30 days, RLS-scoped — no explicit WHERE division_id needed):
      `cutoff = datetime.now(timezone.utc) - timedelta(days=30)`
      Single query: `select(func.count(Transaction.id).label("count"), func.coalesce(func.sum(Transaction.amount), 0).label("volume")).where(Transaction.created_at >= cutoff)`
    - Portfolio value (RLS-scoped):
      `select(func.coalesce(func.sum(PortfolioHolding.market_value), 0))`
    - Active loan count (RLS-scoped):
      `select(func.count(Loan.id)).where(Loan.status == "active")`
    - Return dict:
      ```
      {
        "division": {"name": division.name, "slug": division.slug},
        "transaction_count_30d": int(txn_row.count),
        "transaction_volume_30d": float(txn_row.volume),
        "portfolio_market_value": float(portfolio_result.scalar()),
        "active_loan_count": int(loans_result.scalar()),
      }
      ```
    
    In `backend/app/main.py`:
    - Add `from app.api.analyst import router as analyst_router`
    - Add `app.include_router(analyst_router, prefix="/api/v1")`
      (after rollup_router line)

    Avoid: raw SQL strings, N+1 queries, explicit division_id WHERE on RLS tables
    (RLS handles scoping — adding explicit filters duplicates policy logic).

<task type="auto">
  <name>Task 2: Rewrite analyst page with KPI cards + viewer redirect</name>
  <files>frontend/src/app/(dashboard)/analyst/page.tsx</files>
  <action>
    Rewrite `frontend/src/app/(dashboard)/analyst/page.tsx` as an async Server Component.

    Imports: `auth` from "@clerk/nextjs/server", `redirect` from "next/navigation",
    `KpiCard, KpiGrid` from "@/components/kpi-card", `Role` from "@/lib/roles"

    Interface for summary response:
    ```ts
    interface AnalystSummary {
      division: { name: string; slug: string }
      transaction_count_30d: number
      transaction_volume_30d: number
      portfolio_market_value: number
      active_loan_count: number
    }
    ```

    Page logic:
    1. `const { sessionClaims, getToken } = auth()`
    2. Extract role: `const role = (sessionClaims?.publicMetadata as { role?: string } | undefined)?.role`
    3. Viewer redirect: `if (role === Role.VIEWER || !role) redirect("/")`
    4. `const token = (await getToken()) ?? ""`
    5. `const API_URL = process.env.API_URL ?? "http://localhost:8000"`
    6. Fetch with error guard:
       ```ts
       const res = await fetch(`${API_URL}/api/v1/analyst/summary`, {
         headers: { Authorization: `Bearer ${token}` },
         cache: "no-store",
       })
       const data: AnalystSummary | null = res.ok ? await res.json() : null
       ```
    7. Render:
       - Header: division name from `data?.division.name ?? "Your Division"` in the same
         style as CFO page (h1 + role badge, but use primary-500/20 + primary-400 colors)
       - `<KpiGrid>` with 4 cards:
         - label="Transactions (30d)", value=transaction_count_30d, no prefix, colorScheme="blue"
         - label="Transaction Volume", value=transaction_volume_30d, prefix="$", colorScheme="green"
         - label="Portfolio Value", value=portfolio_market_value, prefix="$", colorScheme="purple"
         - label="Active Loans", value=active_loan_count, no prefix, colorScheme="amber"
       - All values default to 0 if data is null

    Avoid: "use client" directive, useState, useEffect — this is a Server Component.
    Avoid: importing filterbar or CFO-specific components.
  </action>

    (should show no new errors on analyst/page.tsx)
  </verify>
