  <action>
    Add a new endpoint to the existing analyst router in `backend/app/api/analyst.py`.
    Do NOT create a new file — append to the existing router.

    Endpoint: `GET /transactions`
    - Same dependencies as /summary: require_role(ANALYST, CFO), get_current_user, get_scoped_db
    - Query params (all optional):
      - `page: int = Query(default=1, ge=1)`
      - `page_size: int = Query(default=20, ge=1, le=100)`
      - `type: Optional[str] = Query(default=None)` — filter by Transaction.type exact match
      - `category: Optional[str] = Query(default=None)` — filter by Transaction.category exact match
      - `date_from: Optional[date] = Query(default=None)` — filter created_at >= date_from (inclusive, date only)
      - `date_to: Optional[date] = Query(default=None)` — filter created_at <= date_to (inclusive, use end-of-day: date_to + timedelta(days=1))
    - Build a base select on Transaction table (RLS-scoped via get_scoped_db — no WHERE division_id needed)
    - Apply filters conditionally:
      ```python
      stmt = select(Transaction).order_by(Transaction.created_at.desc())
      if type:
          stmt = stmt.where(Transaction.type == type)
      if category:
          stmt = stmt.where(Transaction.category == category)
      if date_from:
          stmt = stmt.where(Transaction.created_at >= datetime.combine(date_from, time.min, tzinfo=timezone.utc))
      if date_to:
          stmt = stmt.where(Transaction.created_at < datetime.combine(date_to + timedelta(days=1), time.min, tzinfo=timezone.utc))
      ```
    - Count query: `select(func.count()).select_from(stmt.subquery())`
    - Paginate: `.offset((page - 1) * page_size).limit(page_size)`
    - Return:
      ```python
      {
          "items": [
              {
                  "id": str(t.id),
                  "type": t.type,
                  "category": t.category,
                  "amount": float(t.amount),
                  "currency": t.currency,
                  "description": t.description,
                  "reference_id": t.reference_id,
                  "status": t.status,
                  "created_at": t.created_at.isoformat(),
              }
              for t in rows
          ],
          "total": total,
          "page": page,
          "page_size": page_size,
          "pages": max(1, math.ceil(total / page_size)),
      }
      ```
    - Additional imports needed: math, time, date from datetime, Optional from typing, Query from fastapi

    Avoid: N+1 queries — use a single count + single paginated select, not per-row fetches.
    Avoid: Returning full ORM objects — serialize to dict explicitly as shown above.
    Avoid: String formatting for date comparisons — use datetime.combine() with timezone.utc.
