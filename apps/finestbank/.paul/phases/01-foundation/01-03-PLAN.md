<objective>
## Goal
Create the PostgreSQL + TimescaleDB schema via Alembic, establish the async SQLAlchemy session layer with division-scoped RLS, and seed all four divisions with realistic mock financial data via Python Faker.

## Purpose
Every Phase 2+ API endpoint reads from this schema. The CFO rollup, analyst drill-downs, transaction feeds, and financial statements all depend on seeded data being present. Without this plan, all subsequent phases have no data to display.

## Output
- SQLAlchemy async models for all 5 financial domains (divisions, transactions, portfolio_holdings, loans, financial_statements, audit_logs)
- Alembic migration creating all tables, enabling TimescaleDB hypertable on `transactions`, and applying RLS policies
- FastAPI async DB session dependency + division-scoped `get_db` dependency (sets `app.division_ids` and `app.role` in DB session)
- `seed.py` script populating ~500 transactions × 4 divisions, 20 holdings × 4, 15 loans × 4, 12 months of financials × 4, audit log entries
</objective>

    Keep existing `get_current_user`. Add:
    ```python
    from app.db.session import AsyncSessionLocal

    async def get_scoped_db(current_user: dict = Depends(get_current_user)):
        """Yields an async DB session with RLS context vars set for the current user."""
        async with AsyncSessionLocal() as session:
            role = current_user.get("role", "viewer")
            divisions = current_user.get("divisions", [])
            division_ids_str = ",".join(str(d) for d in divisions)
            await session.execute(
                text("SELECT set_config('app.role', :role, true), set_config('app.division_ids', :divs, true)"),
                {"role": role, "divs": division_ids_str}
            )
            yield session
    ```

    ```python
    def upgrade():
        # Create divisions
        op.create_table("divisions", ...)

        # Create transactions (with TimescaleDB hypertable)
        op.create_table("transactions", ...)
        op.execute("SELECT create_hypertable('transactions', 'created_at', if_not_exists => TRUE)")

        # Create portfolio_holdings, loans, financial_statements, audit_logs
        op.create_table("portfolio_holdings", ...)
        op.create_table("loans", ...)
        op.create_table("financial_statements", ...)
        op.create_table("audit_logs", ...)

        # Enable RLS on division-scoped tables
        for table in ["transactions", "portfolio_holdings", "loans", "financial_statements"]:
            op.execute(f"ALTER TABLE {table} ENABLE ROW LEVEL SECURITY")
            op.execute(f"ALTER TABLE {table} FORCE ROW LEVEL SECURITY")
            op.execute(f"""
                CREATE POLICY {table}_division_policy ON {table}
                USING (
                    current_setting('app.role', true) = 'cfo'
                    OR division_id::text = ANY(
                        string_to_array(current_setting('app.division_ids', true), ',')
                    )
                )
            """)
    ```
