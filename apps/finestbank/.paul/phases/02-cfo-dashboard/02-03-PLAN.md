<objective>
## Goal
Add optional `division_slug`, `from_period`, and `to_period` query params to the rollup API endpoints, then wire a client-side FilterBar component (division switcher + period range selects) into the CFO page via URL search params.

## Purpose
The CFO dashboard currently shows a fixed 12-period org-wide view. Decision-making requires the ability to isolate a single division or zoom into a specific time window. The division switcher and date range picker complete Phase 2 by making the dashboard interactive — every chart and KPI responds to the user's filter choices.

## Output
- `GET /rollup/kpis` accepts optional `?division_slug=&from_period=&to_period=` query params
- `GET /rollup/trends` accepts same optional params
- `GET /rollup/divisions` accepts optional `?from_period=&to_period=` (always returns all divisions)
- `FilterBar` client component — division dropdown + from/to period selects — pushes URL params on change
- CFO page reads `searchParams`, passes them to all API calls, renders FilterBar above KpiGrid
</objective>

    **Build query string helper (inline, no shared util needed):**
    ```tsx
    function buildQuery(params: Record<string, string | undefined>): string {
      const q = new URLSearchParams()
      for (const [k, v] of Object.entries(params)) {
        if (v) q.set(k, v)
      }
      const s = q.toString()
      return s ? `?${s}` : ""
    }

    const filterParams = {
      division_slug: searchParams.division_slug,
      from_period: searchParams.from_period,
      to_period: searchParams.to_period,
    }
    const qs = buildQuery(filterParams)
    ```
