  <action>
    **1. backend/app/api/rollup.py — new file**

    Create a FastAPI router with `GET /rollup/kpis` (registered at `/api/v1`).
    Secured with `Depends(require_role(Role.CFO))` — analysts get 403.
    Uses a plain `AsyncSessionLocal` session (not `get_scoped_db`) because the CFO
    endpoint intentionally bypasses RLS to aggregate all divisions.

    **Response shape:**
    ```python
    class KpiValue(BaseModel):
        value: float
        change_pct: float  # MoM % change; 0.0 if prior period missing

    class KpiResponse(BaseModel):
        period: str          # e.g. "2026-03"
        kpis: dict[str, KpiValue]  # keys: total_revenue, net_income, total_assets, loan_portfolio
    ```

    **Query logic:**
    1. Get the two most recent distinct `period_label` values from `financial_statements`
       (ordered DESC) — call them `current_period` and `prior_period`.
    2. For each of the 4 KPIs, run two SUM queries (current + prior), then compute:
       `change_pct = (current - prior) / abs(prior) * 100` if prior != 0, else 0.0

    **KPI → DB mapping:**
    | KPI key | Table | Filter |
    |---------|-------|--------|
    | `total_revenue` | `financial_statements` | statement_type='pnl', line_item='Revenue' |
    | `net_income` | `financial_statements` | statement_type='pnl', line_item='Net Income' |
    | `total_assets` | `financial_statements` | statement_type='balance_sheet', line_item='Total Assets' |
    | `loan_portfolio` | `loans` | SUM(outstanding_balance) across all active loans |

    Note: `loan_portfolio` does NOT use financial_statements — it queries the `loans`
    table directly. There is no prior-period concept for it — use change_pct=0.0 for now.

    **SQLAlchemy async queries** — use `select()` from `sqlalchemy` with `session.execute()`.
    Use `func.sum()` for aggregations. All queries are raw SQLAlchemy Core (no ORM relationships needed).

    **Error handling:** If no financial data exists (DB not seeded), return zeros — do not 500.

    Avoid: using `get_scoped_db` — the CFO rollup must read across all divisions without
    RLS filtering. Import `AsyncSessionLocal` directly and open a session in the handler.
    Avoid: N+1 queries — compute both periods in batch, not in a loop per division.

    **2. backend/app/main.py — register rollup router**
    Add:
    ```python
    from app.api.rollup import router as rollup_router
    app.include_router(rollup_router, prefix="/api/v1")
    ```

    ```tsx
    function formatValue(value: number, prefix = ""): string {
      const abs = Math.abs(value)
      if (abs >= 1e9) return `${prefix}${(value / 1e9).toFixed(1)}B`
      if (abs >= 1e6) return `${prefix}${(value / 1e6).toFixed(1)}M`
      if (abs >= 1e3) return `${prefix}${(value / 1e3).toFixed(1)}K`
      return `${prefix}${value.toFixed(0)}`
    }
    ```

  <action>
    **1. frontend/src/app/(dashboard)/cfo/page.tsx — replace placeholder with live data**

    Make this an `async` Server Component. It will:
    1. Call `auth()` from `@clerk/nextjs/server` to get the session token
    2. Fetch `GET /api/v1/rollup/kpis` with `Authorization: Bearer {token}`
    3. Render `KpiGrid` with 4 `KpiCard` instances

    ```tsx
    import { auth } from "@clerk/nextjs/server"
    import { KpiCard, KpiGrid } from "@/components/kpi-card"

    const API_URL = process.env.API_URL ?? "http://localhost:8000"

    export default async function CFOPage() {
      const { getToken } = auth()
      const token = await getToken()

      let data: KpiResponse | null = null
      try {
        const res = await fetch(`${API_URL}/api/v1/rollup/kpis`, {
          headers: { Authorization: `Bearer ${token}` },
          cache: "no-store",
        })
        if (res.ok) data = await res.json()
      } catch {
        // Backend not running — render with null data (shows skeleton state)
      }

      const kpis = data?.kpis
      const period = data?.period ?? "—"

      return (
        <div className="space-y-6">
          <div className="flex items-center justify-between">
            <div className="flex items-center gap-3">
              <h1 className="text-2xl font-bold text-slate-50">CFO Overview</h1>
              <span className="inline-flex items-center rounded-full bg-accent-500/20 px-2.5 py-0.5 text-xs font-medium text-accent-400 ring-1 ring-inset ring-accent-500/30">
                Role: CFO
              </span>
            </div>
            <span className="text-sm text-slate-500">Period: {period}</span>
          </div>

          <KpiGrid>
            <KpiCard
              label="Total Revenue"
              value={kpis?.total_revenue.value ?? 0}
              changePct={kpis?.total_revenue.change_pct ?? 0}
              prefix="$"
              colorScheme="green"
            />
            <KpiCard
              label="Net Income"
              value={kpis?.net_income.value ?? 0}
              changePct={kpis?.net_income.change_pct ?? 0}
              prefix="$"
              colorScheme="blue"
            />
            <KpiCard
              label="Total Assets"
              value={kpis?.total_assets.value ?? 0}
              changePct={kpis?.total_assets.change_pct ?? 0}
              prefix="$"
              colorScheme="purple"
            />
            <KpiCard
              label="Loan Portfolio"
              value={kpis?.loan_portfolio.value ?? 0}
              changePct={kpis?.loan_portfolio.change_pct ?? 0}
              prefix="$"
              colorScheme="amber"
            />
          </KpiGrid>
        </div>
      )
    }
    ```

    Define `KpiResponse` type inline at the top of the file:
    ```tsx
    interface KpiValue { value: number; change_pct: number }
    interface KpiResponse {
      period: string
      kpis: { total_revenue: KpiValue; net_income: KpiValue; total_assets: KpiValue; loan_portfolio: KpiValue }
    }
    ```

    Use `API_URL` (not `NEXT_PUBLIC_API_URL`) — server-side fetch doesn't need the NEXT_PUBLIC prefix.
