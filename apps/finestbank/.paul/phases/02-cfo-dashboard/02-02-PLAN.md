<objective>
## Goal
Add two new rollup endpoints (revenue trend, division comparison) and wire them into the CFO page as Recharts-powered charts below the KPI cards.

## Purpose
KPI cards answer "what is the number right now?" — charts answer "where is it going?" and "which division is driving it?". Without trends and division breakdown, the CFO dashboard is a snapshot, not a tool for decision-making. This plan adds the time-series and cross-division views that make the CFO page useful.

## Output
- `GET /api/v1/rollup/trends` — last 12 periods of org-wide revenue + net income
- `GET /api/v1/rollup/divisions` — current-period revenue + net income per division
- `RevenueChart` — Recharts AreaChart (client component) showing revenue + net income trend
- `DivisionChart` — Recharts BarChart (client component) showing per-division comparison
- CFO page updated to fetch both new endpoints and render charts below KpiGrid
</objective>

    ```python
    class TrendPoint(BaseModel):
        period: str
        total_revenue: float
        net_income: float

    class TrendsResponse(BaseModel):
        data: list[TrendPoint]
    ```

    Query logic:
    1. Run two GROUP BY queries against `financial_statements` (statement_type='pnl'):
       - Query A: `SELECT period_label, SUM(amount) FROM financial_statements WHERE statement_type='pnl' AND line_item='Revenue' GROUP BY period_label ORDER BY period_label DESC LIMIT 12`
       - Query B: same but `line_item='Net Income'`
    2. Build dicts keyed by period_label, merge them
    3. Sort merged results by period_label ASC (oldest → newest for charting)
    4. Return `TrendsResponse(data=[...])`

    Use `select(FinancialStatement.period_label, func.sum(FinancialStatement.amount))` with `.group_by()` and `.where()`.

    If no data: return `TrendsResponse(data=[])` — do not 500.

    Secured with `Depends(require_role(Role.CFO))`.
    Uses raw `AsyncSessionLocal` (same pattern as `/rollup/kpis`).

    ---

    **Endpoint 2: GET /rollup/divisions**

    ```python
    class DivisionKpi(BaseModel):
        name: str
        slug: str
        total_revenue: float
        net_income: float

    class DivisionsResponse(BaseModel):
        period: str
        divisions: list[DivisionKpi]
    ```

    Query logic:
    1. Get the most recent `period_label` from `financial_statements` (same as kpis — DESC LIMIT 1)
    2. Run a single query using conditional aggregation (SQLAlchemy `case()`):
       ```python
       from sqlalchemy import case, func, select
       from app.db.models import Division, FinancialStatement

       stmt = (
           select(
               Division.name,
               Division.slug,
               func.sum(
                   case((FinancialStatement.line_item == "Revenue", FinancialStatement.amount), else_=0)
               ).label("total_revenue"),
               func.sum(
                   case((FinancialStatement.line_item == "Net Income", FinancialStatement.amount), else_=0)
               ).label("net_income"),
           )
           .select_from(FinancialStatement)
           .join(Division, FinancialStatement.division_id == Division.id)
           .where(
               FinancialStatement.statement_type == "pnl",
               FinancialStatement.period_label == current_period,
           )
           .group_by(Division.id, Division.name, Division.slug)
           .order_by(func.sum(
               case((FinancialStatement.line_item == "Revenue", FinancialStatement.amount), else_=0)
           ).desc())
       )
       ```
    3. Return `DivisionsResponse(period=current_period, divisions=[...])`

    If no data: return `DivisionsResponse(period="—", divisions=[])` — do not 500.

    Secured with `Depends(require_role(Role.CFO))`.
    Uses raw `AsyncSessionLocal`.

    ---

    Avoid: adding imports not needed (only add `case` to the existing sqlalchemy import if not already present, and `Division` model import).
    Avoid: N+1 queries — use single query with conditional aggregation for divisions endpoint.

    **Updated fetch section** — fetch all 3 endpoints in parallel:

    ```tsx
    const [kpisRes, trendsRes, divisionsRes] = await Promise.allSettled([
      fetch(`${API_URL}/api/v1/rollup/kpis`, {
        headers: { Authorization: `Bearer ${token}` },
        cache: "no-store",
      }),
      fetch(`${API_URL}/api/v1/rollup/trends`, {
        headers: { Authorization: `Bearer ${token}` },
        cache: "no-store",
      }),
      fetch(`${API_URL}/api/v1/rollup/divisions`, {
        headers: { Authorization: `Bearer ${token}` },
        cache: "no-store",
      }),
    ])

    let data: KpiResponse | null = null
    let trendsData: TrendPoint[] = []
    let divisionsData: DivisionKpi[] = []

    if (kpisRes.status === "fulfilled" && kpisRes.value.ok)
      data = await kpisRes.value.json()
    if (trendsRes.status === "fulfilled" && trendsRes.value.ok) {
      const t = await trendsRes.value.json()
      trendsData = t.data ?? []
    }
    if (divisionsRes.status === "fulfilled" && divisionsRes.value.ok) {
      const d = await divisionsRes.value.json()
      divisionsData = d.divisions ?? []
    }
    ```
