    ### backend/Dockerfile

    Multi-stage production image for Railway:

    ```dockerfile
    FROM python:3.11-slim

    WORKDIR /app

    COPY requirements.txt .
    RUN pip install --no-cache-dir -r requirements.txt

    COPY . .

    EXPOSE 8000

    CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
    ```

    Note: Railway injects $PORT automatically, but FastAPI defaults to 8000 in the CMD.
    For Railway, use `--port ${PORT:-8000}` to respect the injected port:

    ```dockerfile
    CMD ["sh", "-c", "uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-8000}"]
    ```

    ### backend/.env.production.example

    Document all env vars the backend needs in production:

    ```
    # Database (Railway PostgreSQL — auto-set as DATABASE_URL by Railway plugin)
    DATABASE_URL=postgresql+asyncpg://user:password@host:5432/dbname

    # Redis (Railway Redis — auto-set as REDIS_URL by Railway plugin)
    REDIS_URL=redis://default:password@host:6379

    # Clerk (from Clerk dashboard → API Keys)
    CLERK_SECRET_KEY=sk_live_...
    CLERK_PUBLISHABLE_KEY=pk_live_...
    CLERK_JWKS_URL=https://your-clerk-domain.clerk.accounts.dev/.well-known/jwks.json

    # App
    DEBUG=false
    ALLOWED_ORIGINS=https://your-app.vercel.app
    ```

    ### frontend/vercel.json

    Minimal Vercel config for Next.js:

    ```json
    {
      "framework": "nextjs",
      "buildCommand": "npm run build",
      "outputDirectory": ".next",
      "installCommand": "npm install"
    }
    ```

    Note: Vercel auto-detects Next.js — this file is optional but makes config explicit.
    Do NOT add rewrites or redirects — Next.js routing handles everything.
